# Mathematical Verification & Stamp of Trust

Because `algebrax` implements foundational linear algebra, semirings, discrete exterior calculus, spectral transforms,
and Lie algebras in **100% pure Python with zero required runtime dependencies**, mathematical correctness cannot be
left to conventional unit tests alone.

To earn a verifiable **Stamp of Trust**, `algebrax` employs a **Multi-Layered Verification Suite** housed under
`tests/verifications/` (alongside the built-in law verifier in `tests/algebrax/test_verification.py`). Every
mathematical claim is continuously cross-checked against external industry-standard reference engines (**NumPy**,
**SciPy**, **LAPACK**, **PocketFFT**) and rigorous mathematical invariants.

---

## 1. Verification Methodologies & Categories

Each test in `tests/verifications/` is categorized by its formal verification methodology and pytest marker:

| Category / Marker    | Verification Methodology                                                         | How It Establishes Mathematical Truth                                                                                                                                                                                                                                                                                                   |
|:---------------------|:---------------------------------------------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **`differential`**   | **Comparative / Differential Oracle Testing** *(McKeeman, 1998)*                 | Pits `algebrax` sparse dictionary algorithms directly against battle-tested C/Fortran reference libraries (`numpy.linalg`, `scipy.linalg`, `scipy.sparse.linalg`, `numpy.fft`, `scipy.signal`) across deterministic and Hypothesis-generated inputs.                                                                                    |
| **`axiomatic`**      | **Property-Based Algebraic Law Testing** *(MacIver et al., 2019)*                | Uses **Hypothesis** to generate adversarial random inputs (including $\pm\infty$, boundary probabilities, and exact rationals) and verifies universal algebraic axioms (associativity, commutativity, distributivity, identity, annihilation).                                                                                          |
| **`Exact Rational`** | **Infinite-Precision $\mathbb{Q}$ Verification**                                 | Evaluates semirings and matrix operations over Python's exact `fractions.Fraction` field, eliminating IEEE 754 floating-point rounding tolerances ($\epsilon = 0$).                                                                                                                                                                     |
| **`metamorphic`**    | **Metamorphic Invariant Relations** *(Chen et al., 1998)*                        | Verifies necessary structural conservation laws across input transformations when no external oracle exists (e.g., $(A \otimes B)^T = B^T \otimes A^T$, boundary nilpotency $\partial^2 = 0$, graph vertex permutation conjugacy $L(P A P^T) = P L(A) P^T$).                                                                            |
| **`pit`**            | **Schwartz–Zippel Polynomial Identity Testing** *(Schwartz, 1980; Saxena, 2014)* | Defeats exponential symbolic monomial blowup by evaluating high-degree identities (such as the Jacobi identity on 14-dimensional $\mathfrak{g}_2$ and 52-dimensional $\mathfrak{f}_4$) at random integer coordinates in $S \subset \mathbb{Z}$, bounding false-positive error probability to $\le (d/ \lvert S \rvert)^k \le 10^{-16}$. |
| **`certificates`**   | **Proof-Carrying Solver (PCS) Witnesses**                                        | Verifies the output of expensive $O(N^3)$ numerical solvers (e.g., Helmholtz–Hodge decomposition, LU, QR, Cholesky, SVD, CG, Fiedler) via fast, independent $O(\text{nnz})$ algebraic witness checks (orthogonality, curl/divergence annihilation, exact reconstruction).                                                               |
| **`mms`**            | **Method of Manufactured Solutions** *(Roache, 2002)*                            | Injects exact analytical harmonic extensions and boundary conditions to verify discrete exterior calculus, PDE diffusion, and sheaf Laplacians against known solutions.                                                                                                                                                                 |
| **`smt`**            | **Automated SMT / `Z3` Deductive Formal Proofs** *(de Moura & Bjørner, 2008)*    | Encodes semiring, dioid, lattice, and $2 \times 2$ matrix equations into `z3-solver` Real/Boolean ASTs and proves `check(Not(Law)) == unsat`, guaranteeing universal mathematical truth across $\mathbb{R}^n$ and $\mathbb{B}^n$.                                                                                                       |

## 3. Running the Verification Suite

You can run the entire verification suite or filter by verification methodology using `pytest` markers:

```bash
# Run all verification tests (196 tests in tests/verifications/ + 37 in tests/algebrax/test_verification.py = 233 total)
uv run pytest tests/verifications/ tests/algebrax/test_verification.py -v

# Run only comparative / differential tests against NumPy, SciPy, NetworkX & SymPy
uv run pytest tests/verifications/ -m differential -v

# Run only Hypothesis axiomatic property-based tests
uv run pytest tests/verifications/ -m axiomatic -v

# Run only Method of Manufactured Solutions (MMS) sheaf/PDE tests
uv run pytest tests/verifications/ -m mms -v

# Run only metamorphic invariant tests
uv run pytest tests/verifications/ -m metamorphic -v

# Run only Schwartz-Zippel randomized polynomial identity tests (PIT)
uv run pytest tests/verifications/ -m pit -v

# Run only proof-carrying solver certificate checks
uv run pytest tests/verifications/ -m certificates -v

# Run only automated SMT / Z3 formal mathematical proofs (-m smt or -m formal_smt)
uv run pytest tests/verifications/ -m smt -v
```
